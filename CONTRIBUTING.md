# دليل المساهمة | Contributing Guide

## كيفية المساهمة | How to Contribute

شكراً لاهتمامك بالمساهمة في Ipload! نرحب بجميع أنواع المساهمات.

Thank you for your interest in contributing to Ipload! We welcome all types of contributions.

### خطوات المساهمة | Steps to Contribute

1. **Fork المشروع** | Fork the project
2. **إنشاء فرع جديد** | Create a new branch
   ```bash
   git checkout -b feature/amazing-feature
   ```
3. **تنفيذ التغييرات** | Make your changes
4. **Commit التغييرات** | Commit your changes
   ```bash
   git commit -m 'Add some amazing feature'
   ```
5. **Push إلى الفرع** | Push to the branch
   ```bash
   git push origin feature/amazing-feature
   ```
6. **فتح Pull Request** | Open a Pull Request

### إرشادات الكود | Code Guidelines

- اكتب كود نظيف وقابل للقراءة | Write clean and readable code
- أضف تعليقات عند الحاجة | Add comments when necessary
- اتبع أسلوب الكود الموجود | Follow existing code style
- اختبر التغييرات قبل الإرسال | Test changes before submitting

### الإبلاغ عن المشاكل | Reporting Issues

إذا وجدت مشكلة، يرجى فتح issue جديد مع:

If you find an issue, please open a new issue with:

- وصف واضح للمشكلة | Clear description of the issue
- خطوات إعادة إنتاج المشكلة | Steps to reproduce
- لقطات شاشة إن أمكن | Screenshots if possible
- معلومات النظام والمتصفح | System and browser info

### اقتراح ميزات جديدة | Suggesting Features

نرحب بأفكاركم لتحسين Ipload! افتح issue مع:

We welcome your ideas to improve Ipload! Open an issue with:

- وصف الميزة المقترحة | Description of proposed feature
- حالات الاستخدام | Use cases
- أمثلة إن أمكن | Examples if possible

## شكراً | Thank You

شكراً لمساهمتك في جعل Ipload أفضل!

Thank you for contributing to make Ipload better!
