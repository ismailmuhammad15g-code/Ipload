# إصدار 1.0.0 | Version 1.0.0

تاريخ الإصدار | Release Date: 2025-10-28

## 🎉 الميزات الجديدة | New Features

### 🌐 واجهة المستخدم | User Interface
- واجهة عربية كاملة وسهلة الاستخدام
- تصميم عصري ومتجاوب يعمل على جميع الأجهزة
- ألوان جذابة وتدرجات حديثة
- Full Arabic interface, easy to use
- Modern responsive design for all devices
- Attractive colors and modern gradients

### 📤 رفع الملفات | File Upload
- رفع ملفات بسهولة حتى 10MB
- عرض تقدم الرفع
- معاينة اسم الملف قبل الرفع
- رسائل نجاح وخطأ واضحة
- Easy file upload up to 10MB
- Upload progress display
- File name preview before upload
- Clear success and error messages

### 🌍 عرض IP | IP Display
- عرض عنوان IP الخاص بالمستخدم تلقائياً
- زر تحديث لتحديث العنوان
- عرض جميل ومميز
- Automatic user IP address display
- Refresh button to update address
- Beautiful and distinctive display

### 📊 إدارة الملفات | File Management
- عرض قائمة بجميع الملفات المرفوعة
- عرض حجم كل ملف
- عرض تاريخ رفع الملف
- تحديث القائمة ديناميكياً
- Display list of all uploaded files
- Show file size
- Show upload date
- Dynamic list update

### 🔒 الأمان | Security
- حد أقصى لحجم الملف (10MB)
- تسمية ملفات آمنة ومميزة
- تتبع عنوان IP للرافع
- حماية من الكتابة فوق الملفات
- Maximum file size limit (10MB)
- Safe and unique file naming
- IP address tracking
- Protection against file overwriting

### 🛠️ API
- `/api/ip` - الحصول على عنوان IP
- `/api/upload` - رفع ملف
- `/api/files` - قائمة الملفات
- استجابات JSON واضحة
- Get IP address
- Upload file
- List files
- Clear JSON responses

## 🚀 التثبيت والتشغيل | Installation & Running

```bash
# استنساخ المشروع | Clone repository
git clone https://github.com/ismailmuhammad15g-code/Ipload.git

# الدخول للمجلد | Navigate to directory
cd Ipload

# تثبيت المكتبات | Install dependencies
npm install

# التشغيل | Run
npm start
```
